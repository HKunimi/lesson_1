# 作業時間計測アプリ 要件定義書
 
## 1. サービス概要
 
### 1.1 サービス名
 
Project Tracker
 
### 1.2 コンセプト
 
**「時間を見える化して、生産性を向上させる」**
 
タイマー計測、手動入力、カテゴリ管理。シンプルな操作で作業時間を記録し、分析できる時間管理アプリ。
 
### 1.3 ターゲットユーザー
 
- フリーランスや個人事業主で作業時間を管理したい人
- 複数プロジェクトの時間配分を把握したい人
- 生産性向上を目指すビジネスパーソン
- 20代〜50代の個人・チームユーザー
 
### 1.4 提供価値
 
- **簡単記録**: タイマーまたは手動入力で素早く記録
- **カテゴリ管理**: プロジェクトやタスクごとに時間を整理
- **分析機能**: 時間の使い方を可視化し、改善点を発見（プレミアム）
 
## 2. 機能要件
 
### 2.1 主要機能（3つのみ）
 
### 機能1: 作業時間の記録
 
#### タイマー機能
- スタート/ストップボタンでリアルタイム計測
- 一時停止/再開機能
- 経過時間の表示（00:00:00形式）
- タイマー実行中は他のページでも継続
 
#### 手動入力機能
- 開始時刻と終了時刻を選択
- または作業時間を直接入力（時間・分単位）
- 過去の日付での記録も可能
 
### 機能2: カテゴリ管理
 
- プロジェクト/タスクカテゴリの作成・編集・削除
- カテゴリごとの色分け設定
- カテゴリ選択は記録時に必須
- よく使うカテゴリのお気に入り登録
 
### 機能3: ダッシュボード
 
**無料版**: 基本的な時間表示
 
- 今日の作業時間合計
- 今週の作業時間合計
- 今月の作業時間合計
- 直近の作業履歴（最新10件）
 
**プレミアム版**: 詳細な時間分析（高度な分析機能）
 
- 日次・週次・月次・年次の期間切り替え
- 期間セレクター（カスタム期間選択可能）
- カテゴリ別の詳細分析
  - 円グラフ：時間配分の可視化
  - 棒グラフ：カテゴリ別作業時間の比較
  - ヒートマップ：日別の作業密度
- 生産性指標
  - 平均作業時間
  - 最も集中した時間帯
  - カテゴリごとの推移
 
### 2.2 必須機能（主要機能を支える最小限の機能）
 
### ユーザー認証
 
- メールアドレスでのログイン（ソーシャルログインには未対応）
- パスワードリセット
- セッション管理
 
### データ管理
 
- 作業履歴の閲覧・検索・フィルタリング
- 作業記録の編集（時間、カテゴリ、メモ）
- 作業記録の削除
- データのエクスポート（CSV形式）
 
### その他の基本機能
 
- 作業メモの追加（各記録に簡単なメモを付与）
- タイムゾーン設定
- 週の開始曜日設定（月曜/日曜）
 
## 3. 非機能要件
 
### 3.1 パフォーマンス
 
- タイマー開始/停止：即座に反応
- ダッシュボードの表示：2秒以内
- グラフ描画：スムーズなアニメーション
 
### 3.2 ユーザビリティ
 
- デスクトップ/モバイル対応（レスポンシブデザイン）
- ワンクリックでタイマー開始
- キーボードショートカット対応
- 作業中のステータスを常に表示
- 共通ヘッダーによるナビゲーション
 
### 3.3 セキュリティ
 
- ユーザーデータの安全な管理
- HTTPS通信
- プライバシー設定（データの公開範囲制御）
 
## 4. 期間分析機能の詳細仕様（プレミアム機能）
 
### 4.1 期間切り替えUI
 
- **タブ切り替え**
  - 日次 / 週次 / 月次 / 年次をタブで切り替え
  - アクティブタブはグラデーション背景
  - スムーズなトランジションアニメーション
 
### 4.2 期間セレクター
 
- **日次**
  - 今日 / 昨日
  - カレンダーピッカーで任意の日付選択可能
 
- **週次**
  - 今週 / 先週
  - 週の開始は設定で変更可能
  - カスタム期間選択可能
 
- **月次**
  - 今月 / 先月
  - 年月ピッカーで任意の月選択可能
 
- **年次**
  - 今年 / 去年
  - 年ピッカーで任意の年選択可能
 
### 4.3 比較機能
 
- 選択した期間と前期間の比較
- 増減率の表示（％表示）
- 増減をカラーコーディング（増加:緑、減少:赤）
 
### 4.4 データ表示
 
- **サマリーカード**
  - 期間内の総作業時間
  - 前期間比較
  - 1日平均作業時間
 
- **詳細グラフ**
  - 時系列グラフ：作業時間の推移
  - カテゴリ別積み上げグラフ
  - ヒートマップ：日別・時間帯別の作業密度
 
- **レポート機能**
  - PDF/CSVエクスポート
 
## 5. 技術仕様
 
- **フロントエンド**: Next.js、TypeScript、Tailwind CSS、Shadcn UI
- **バックエンド**: Next.js API Routes
- **データベース**: Supabase（PostgreSQL）
  - ローカルは Supabase CLI にて検証（Dockerは未使用）
- **認証**: Clerk（Clerkダッシュボードからキーを取得する必要あり）
  - 認証機能はすべてClerkの組み込みコンポーネントを使用
- **課金システム**: Clerk Billing（Stripe連携が必要、開発後半で実装）
  - 課金機能はすべてClerkの組み込みコンポーネントを使用
- **グラフライブラリ**: Recharts（プレミアム機能で使用）
- **日時処理**: date-fns, date-fns-tz
- **ホスティング**: Vercel
- **その他**:
    - フォーム：react-hook-form
    - アイコン: lucide-react
    - Lint: ESLint, Prettier
- **テスト**: MVP目的のためテストは書かない
 
### 開発時の注意事項
- Clerk Billingは標準のnpmパッケージではなく、Clerkダッシュボードでの設定が必要
- Clerkダッシュボードでプランを作成する際は、スラグを「premium」に設定
- SupabaseとClerkの認証連携では、カスタムヘッダー方式でRLSを実装
- Supabaseローカル開発時はポート競合に注意（`supabase stop --all`で解決）
- Supabaseでユーザーテーブルを作る場合でも、ClerkのWebhook機能は使用しない
  - usersテーブルなどが必要であれば、初回データ登録時に作成する
- プレミアム機能はClerkのhas()関数でプラン確認を行う
 
## 6. 画面構成
 
### 6.1 公開ページ
 
- **トップページ** (`/`): サービス紹介、機能説明、料金プラン
- **料金ページ** (`/pricing`): Clerk BillingのPricingTableを表示
- **サインイン** (`/sign-in`): Clerkのサインインコンポーネント
- **サインアップ** (`/sign-up`): Clerkのサインアップコンポーネント
 
### 6.2 認証必須ページ
 
- **ダッシュボード** (`/dashboard`): メイン画面、タイマーと作業履歴を表示
- **カテゴリ管理** (`/categories`): カテゴリの作成・編集・削除
- **レポート** (`/reports`): 詳細な分析レポート（プレミアム機能）
- **ユーザー設定** (`/user-setting`): Clerkのアカウント管理コンポーネント
 
### 6.3 共通コンポーネント
 
- **ヘッダー**: ロゴ、ナビゲーション、ユーザーメニュー
- **フッター**: コピーライト表示（トップページのみ）
 
## 7 料金体系
 
### 7.1 無料プラン
 
- 作業時間記録
- タイマー機能・手動入力機能
- カテゴリ管理
- 日・週・月の合計時間表示
- 作業履歴閲覧
- CSVエクスポート
 
### 7.2 プレミアムプラン
 
- 月額: $10（ドル表記）
- **高度な分析機能**
  - 日次・週次・月次・年次の期間切り替え
  - 過去データとの比較・トレンド分析
  - カテゴリ別の詳細グラフ（円グラフ・棒グラフ・ヒートマップ）
  - 生産性指標の分析
  - PDFレポート生成
- **拡張機能**
  - カテゴリ無制限作成
  - カスタムレポートテンプレート
  - 目標時間設定と達成率表示
- **デザイン**
  - プレミアム感のあるUI
  - アニメーション効果
  - 高級感のあるグラデーション
- 無料プランの全機能含む
